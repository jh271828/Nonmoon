# HBM 패키징 신호 경로와 Interposer

## 오늘 직접 학습한 지식

Die -> Micro Bump -> Interpose -> Substrate -> PCB

Solder Ball이 뭔지도 모르겠어

Bump와 SolderBall을 이어주기 위해?

전류의 흐름을 조절하기 위해서?

HBM에서 Interposer가 필요한 이유는 배선때문이다

Die는 나노미터 단위, PCB는 밀리미터 단위이므로 스케일이 매우 다르다. 따라서 Die에서 나온 신호를 Micro Bump가 연결하고, Interposer가 빽빽하게 배선을 구성하며, Package Substrate로 Interposer와 Substrate를 연결하고, 마지막으로 chip과 PCB를 연결하기 위해 Solder Ball이 필요하다

Die는 나노미터 단위, PCB는 밀리미터 단위이므로 스케일이 매우 다르다.

따라서 Die에서 나온 신호를 Micro Bump가 연결하고, Interposer가 빽빽하게 배선을 구성하며, Package Substrate로 Interposer와 Substrate를 연결하고, 마지막으로 chip과 PCB를 연결하기 위해 Solder Ball이 필요하다

HBM에서 Interposer가 필요한 이유는 배선때문이다

Die -> Micro Bump -> Interpose -> Substrate -> PCB

## 취약 영역

- Die Pad와 RDL의 관계
- Package Substrate의 내부 배선 구조
- Interposer가 필요한 이유를 'Substrate가 Die 수준의 높은 배선 밀도를 직접 처리할 수 없기 때문'이라고 완전한 문장으로 설명하는 것
- TSV와 Micro Bump의 역할 분담
