# HBM 패키징의 기본 신호 경로

## 오늘 직접 학습한 지식

오늘 직접 학습한 지식

HBM 패키징의 기본 신호 경로:
Die → Die Pad(RDL) → Micro Bump → Interposer → Package Substrate → Solder Ball → PCB
Micro Bump는 Die와 Interposer를 연결하고, Solder Ball은 Package와 PCB를 연결한다.
Interposer는 연산을 위한 칩이 아니라 초미세 배선을 제공하는 실리콘 배선판이다.
HBM에서 Interposer가 필요한 이유는 Substrate가 Die 수준의 높은 배선 밀도를 직접 처리할 수 없기 때문임을 이해했다.
