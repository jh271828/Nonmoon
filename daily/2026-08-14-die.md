# Die 신호 경로 설명 링크 반영

## 오늘 직접 학습한 지식

[Die 신호 경로 설명](https://chatgpt.com/c/6a748612-7bd8-83ee-812f-5bafd83e8be7)

기존 학습에서 내가 직접 설명한 내용: "Die는 웨이퍼를 구성하는 가장 기초적인 단위이자, 연산을 할 수 있는 기능적인 단위. Die의 배선은 수 나노미터 수준이기 때문에, PCB가 사용할 수 있는 스케일과 호환되기 위해 패키지를 만든다?" 이후 Die Pad에 대해 질문했고, "Die Pad는 집 문, Substrate는 역?"이라고 비유했다. Micro Bump의 위치에 대해서는 "Die와 Substrate사이?"라고 답했고, TSV에 대해서는 "Die를 관통하는 통로가 있다."라고 이해했다. Interposer가 필요한 이유에는 "배선간격이 너무 좁아서?"라고 답했다. 이후 HBM 패키징의 기본 신호 경로를 Die → Die Pad(RDL) → Micro Bump → Interposer → Package Substrate → Solder Ball → PCB로 정리했다. Micro Bump는 Die와 Interposer를 연결하고, Solder Ball은 Package와 PCB를 연결한다. Interposer는 연산을 위한 칩이 아니라 초미세 배선을 제공하는 실리콘 배선판이며, HBM에서 Interposer가 필요한 이유는 Substrate가 Die 수준의 높은 배선 밀도를 직접 처리하기 어렵기 때문이라고 이해했다.

## 취약 영역

- Die Pad와 RDL의 관계
- Package Substrate의 내부 배선 구조
- TSV와 Micro Bump의 역할 분담

- TSV와 Micro Bump는 각각 신호 경로의 어디를 담당하는가?
